# Teacher Guide — Wake Up Your Cutebot

Session goals
- Introduce sequence and parameters; encourage experimentation.

Setup
- Ensure each group has a Cutebot and micro:bit.
- Prepare start/finish lines and measuring tape if available.

Hints for volunteers
- Ask students to predict before they run their code.
- When a robot goes too far, prompt them to adjust `duration` or `speed`.

Assessment
- Can the student make the robot stop at the finish line?
- Can they explain how changing a parameter affected the movement?

Notes
- Copy starter and finished MakeCode files into `code/` for later reference.
