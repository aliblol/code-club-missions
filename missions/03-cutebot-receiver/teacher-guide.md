# Teacher Guide — Don't Crash!

Session goals
- Teach conditional logic with sensor input; encourage safe testing.

Setup
- Provide objects for students to test distances.

Hints for volunteers
- Ask students to record sensor values before setting thresholds.
- Encourage testing at different speeds to see effect on stopping distance.

Assessment
- Can the student reliably stop or avoid an obstacle?
- Can they explain the `if` condition used?

Notes
- Store sample MakeCode projects in `code/` for demonstrations.
