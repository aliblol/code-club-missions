# Mission 2: Robot Navigator

## 🎯 Your mission

Use loops to make the Cutebot follow a planned route using fewer blocks.

## 🧠 Today's idea

Today we're learning about:

**Loops and algorithms**

This means we are learning how to repeat steps in a smart way and plan a route so the robot follows a clear sequence of actions.

---

## 🔎 Explore

Try this:

1. Build a simple grid on the floor with START and FINISH.
2. Program five `forward` steps in a row and run them.
3. Replace the five steps with a `repeat 5 times` block and run again.

### What happens if...

- you change the repeat count? 
- you nest one `repeat` inside another? 
- you change the speed inside the loop?

---

## 🛠️ Design

### ⭐ Challenge 1

Use a `repeat` block to cross a short section of the grid.

### ⭐⭐ Challenge 2

Program the Cutebot to navigate from START to FINISH using loops.

### ⭐⭐⭐ Challenge 3

Compress a movement sequence into nested loops to shorten code.

---

## 💡 Invent

You've completed the mission! Now see if you can:

- Make a robot dance using loops.
- Create the same route using fewer blocks.
- Add LEDs timed inside loops.

There is no single right answer.
