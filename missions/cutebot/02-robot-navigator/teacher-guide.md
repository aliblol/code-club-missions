# Teacher Guide — Robot Navigator

Session goals
- Teach loops and basic algorithm thinking; encourage concise code.

Setup
- Prepare a simple grid and a few obstacles for route planning.

Hints for volunteers
- Ask students how they might shorten repeated code.
- Suggest using a `repeat N times` block and testing with different N.

Assessment
- Can the student use a loop to replace repeated commands?
- Can they explain why the loop helps?

Notes
- Save student projects to `code/` for reference.
