# Mission 1: Wake Up Your Cutebot

## 🎯 Your mission

Make the Cutebot move reliably and learn how small changes to parameters change behaviour.

## 🧠 Today's idea

Today we're learning about:

**Sequence and parameters**

This means we are learning how to plan instructions in the correct order and tune the values that control movement so the robot behaves as expected.

---

## 🔎 Explore

Try this:

1. Connect the Cutebot and micro:bit.
2. Run `forward` for 1 second at medium speed.
3. Run `forward` for 1 second at low speed.

### What happens if...

- you increase the `speed`? 
- you increase the `duration`? 
- you run one motor faster than the other?

---

## 🛠️ Design

### ⭐ Challenge 1

Drive from START to FINISH and stop.

### ⭐⭐ Challenge 2

Create a 6-step robot dance using movement blocks.

### ⭐⭐⭐ Challenge 3

Make a figure-of-8 using different turn durations and motor speeds.

---

## 💡 Invent

You've completed the mission! Now see if you can:

- Add LEDs or sounds to the dance.
- Change the dance to use fewer blocks.
- Make the robot move differently at different speeds.

There is no single right answer.

---

## 🧠 Think

- What happened?
- Why did it happen?
- What would you change?
- What could you try next?
