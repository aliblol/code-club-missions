# Mission 4: Add the Countdown

## 🎯 Your mission

Add a 30-second countdown and make the game end with a win when time runs out.

## 🧠 Today's idea

**Countdown events**

A timer counts down while the game runs. The game can respond to the event that fires when the timer reaches zero.

## 🔎 Explore

Open the starter `main.ts`.

1. Find the score and lives display. Which section of MakeCode created it?
2. Look in **Info** for a countdown block and an event for when it ends.

### What happens if...

- the timer is 10 seconds instead of 30?
- you remove the countdown-end event?

## 🛠️ Design

### ⭐ Challenge — Add the timer and win ending

Start a 30-second countdown, then make the game end with a win when the timer reaches zero.

💡 Look in **Info** for the countdown and its end event. Look in **Game** for the win block.
