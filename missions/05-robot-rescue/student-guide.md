# Mission 5: Robot Rescue

## 🎯 Your mission

Combine movement, sensors and variables to find and signal a rescue.

## 🧠 Today's idea

Today we're learning about:

**Combining concepts and using variables**

---

## 🔎 Explore

Try this:

1. Break the problem into move, detect, avoid, and signal steps.
2. Implement and test each part separately.

### What happens if...

- you change the variable that stores `distance`? 
- you react differently for near vs far obstacles? 
- you add a time limit to the mission?

---

## 🛠️ Design

### ⭐ Challenge 1

Reach the rescue zone and stop.

### ⭐⭐ Challenge 2

Avoid an obstacle and continue to the rescue zone.

### ⭐⭐⭐ Challenge 3

Complete the rescue mission under a time limit or with fewer steps.

---

## 💡 Invent

You've completed the mission! Now see if you can:

- Add an alarm or flashing LEDs when rescue completes.
- Implement different avoidance strategies selected by a variable.
- Create a countdown or timed challenge.

There is no single right answer.

---

## 🧠 Think

- What happened?
- Why did it happen?
- What would you change?
- What could you try next?

---

## 🏁 Mission complete!

I can...

- [ ] Combine movement and sensors into a single program.
- [ ] Use variables to store sensor readings.
- [ ] Signal when the rescue is complete.
