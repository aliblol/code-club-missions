📋 How to import the starter code

  1. Click the "Copy Code" button above
  2. Go to MakeCode Arcade (or MakeCode micro:bit)
  3. Create a new project
  4. Switch to js editor
  5. Delete any starter code, then paste your code using Ctrl+V (or Cmd+V on Mac)
  6. Switch back to blocks editor
  7. Press the play button to run it!
